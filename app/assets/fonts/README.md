# Bundled fonts

`DejaVuSans.ttf` / `DejaVuSans-Bold.ttf` — used by `Reports::ProvinceReportPdf` to
render Vietnamese diacritics (Prawn's built-in AFM fonts are Latin-1 only).

DejaVu Fonts are released under a permissive license (Bitstream Vera Fonts
Copyright + public-domain additions); free to use, embed, and redistribute.
